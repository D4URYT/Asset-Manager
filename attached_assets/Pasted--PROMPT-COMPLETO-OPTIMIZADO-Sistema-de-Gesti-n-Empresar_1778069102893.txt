🚀 PROMPT COMPLETO OPTIMIZADO
Sistema de Gestión Empresarial Web (Node.js + Dashboard + Testing)

Desarrollar un portal web de gestión empresarial moderno, escalable y totalmente testeable, utilizando Node.js como tecnología principal en el backend. El sistema debe permitir la administración de información mediante operaciones CRUD, ofrecer una experiencia de usuario profesional tipo dashboard empresarial y estar preparado para pruebas automatizadas (testing).

🎯 OBJETIVO

Construir una aplicación web dinámica que:

Permita gestionar entidades empresariales (usuarios, productos, clientes o publicaciones)
Implemente operaciones CRUD completas
Ofrezca una interfaz moderna tipo dashboard profesional
Sea completamente responsiva
Siga buenas prácticas de desarrollo
Esté preparada para testing (unitario, integración y E2E)
